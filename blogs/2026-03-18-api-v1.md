平素よりPAY.JPをご愛顧いただき、誠にありがとうございます。 以前、掲載させていただきました「 海外発行カードで取得できるオーソリ期限を「最大7日まで」に制限いたします（2026年8月開始予定） 」( https://pay.jp/info/2026-03-03-130000 ) につきまして、API v1 におけるテストモードにて動作確認ができるようになりました。 https://docs.pay.jp/v1/authcapture https://docs.pay.jp/v1/api/#cardオブジェクト テストモード 4000000900000003 が海外カードと判定されるテストカードとなります。このカードを利用されますと、 card.is_jp が false と判定され、 オーソリ期限延長で expired_at に7日を超える期限を指定した場合、期限は7日に短縮されます。 ライブモード 発行国に関わらず、どのカードでもリクエストした値が設定される従来の仕様のままとなっております。ご注意ください。
